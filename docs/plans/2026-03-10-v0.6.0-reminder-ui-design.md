# Todo/Plan/Target 到期提醒 UI 设计方案

> 版本: v1.0
> 日期: 2026-03-10
> 状态: 待实现

---

## 一、需求概述

### 1.1 背景

当前通知系统后端已完整实现，但用户无法在前端为具体的 Todo/Plan/Target 设置到期提醒。

### 1.2 目标

为 Todo、Plan、Target 添加到期提醒功能，允许用户设置多个提醒时间点。

### 1.3 需求确认

| 决策项   | 选择                      |
| -------- | ------------------------- |
| 入口位置 | Form 内 + Item 快捷按钮   |
| 提醒方式 | 多选提醒（支持多个时间）  |
| 通知渠道 | 默认渠道（Settings 配置） |

---

## 二、数据结构设计

### 2.1 现有结构（单个提醒）

```typescript
NotificationSettings {
  id: string;
  entity_type: "todo" | "plan" | "target";
  entity_id: string;
  reminder_minutes: number;  // 单个时间
  reminder_sent: boolean;
}
```

### 2.2 新结构（多个提醒）

```typescript
NotificationSettings {
  id: string;
  entity_type: "todo" | "plan" | "target";
  entity_id: string;
  reminder_times: number[];  // [5, 60, 1440] 多个时间（分钟）
  reminder_sent: boolean[];  // 对应每个提醒的发送状态
  created_at: string;
  updated_at: string;
}
```

### 2.3 数据迁移策略

- 现有 `reminder_minutes` 迁移为 `reminder_times: [reminder_minutes]`
- 后端自动处理迁移，无需用户干预

## 五、API 设计

### 5.1 现有 API

```typescript
// 获取实体的提醒设置
getNotificationSettings(entityType: string, entityId: string): Promise<NotificationSettings>

// 设置提醒（需修改支持多时间）
setNotificationSettings(
  entityType: string,
  entityId: string,
  reminderTimes: number[]  // 改为数组
): Promise<void>

// 删除提醒
deleteNotificationSettings(entityType: string, entityId: string): Promise<void>
```

### 5.2 调用流程

```typescript
// 1. 创建/编辑时保存提醒
const saveTodo = async (todoData) => {
  // 保存 Todo
  const todo = await createTodo(todoData);

  // 保存提醒设置
  if (reminderTimes.length > 0) {
    await setNotificationSettings("todo", todo.id, reminderTimes);
  } else {
    await deleteNotificationSettings("todo", todo.id);
  }
};

// 2. 快捷设置提醒
const handleQuickReminder = async (times: number[]) => {
  if (times.length > 0) {
    await setNotificationSettings("todo", todoId, times);
  } else {
    await deleteNotificationSettings("todo", todoId);
  }
  onUpdate(times);
};
```
