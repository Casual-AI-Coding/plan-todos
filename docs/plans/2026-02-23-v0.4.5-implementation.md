# v0.4.5 数据管理功能实现计划

> 创建日期：2026-02-23
> 版本：0.4.5

---

## 概述

v0.4.5 版本主要实现数据管理功能，包括生成测试数据和重置数据。

---

## 功能设计

### 1. 生成测试数据 (Seed Test Data)

| 项目 | 数量 | 说明 |
|------|------|------|
| Tag | 6 | 标签 |
| Todo | 10 | 各种状态和优先级 |
| Plan | 3 | 长期计划 |
| Task | 15 | 关联到 Plan |
| Target | 5 | 目标 |
| Step | 10 | 关联到 Target |
| Milestone | 5 | 里程碑 |
| Circulation | 8 | 周期+计数打卡 |
| CirculationLog | 30 | 打卡记录 |

### 2. 重置数据 (Reset Data)

- 清空所有业务数据（保留表结构）
- 可选择是否保留标签和设置
- 重置前显示确认对话框

---

## API 设计

### 前端 API (src/lib/api.ts)

```typescript
// 生成测试数据
export async function seedTestData(): Promise<{
  todos: number;
  plans: number;
  tasks: number;
  targets: number;
  steps: number;
  milestones: number;
  circulations: number;
  circulation_logs: number;
  tags: number;
}>

// 重置数据
export async function resetData(options?: {
  keepTags?: boolean;
  keepSettings?: boolean;
}): Promise<void>
```

### 后端 API (src-tauri/src/commands/)

- `seed_test_data` - 生成测试数据
- `reset_data` - 重置数据
