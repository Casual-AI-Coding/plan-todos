**问题**：打包的 APK 没有使用项目的 logo 作为 icon。

**解决方案**：检查 `tauri.conf.json` 中的 icon 配置，确保使用项目自己的图标资源。

**具体操作**：

1. 检查 `src-tauri/icons/` 目录下的图标文件
2. 确认 `tauri.conf.json` 中 `bundle.icon` 指向正确的图标路径
3. 如果使用默认 Tauri 图标，替换为项目 Logo (PNG 格式，参考现有图标尺寸)
4. 重新打包验证

### 6.3 设计方案

#### 6.3.1 系统主题跟随

使用 `matchMedia` API：

```tsx
export function useSystemTheme() {
  const [systemTheme, setSystemTheme] = useState<'light' | 'dark'>('light');

  useEffect(() => {
    const mediaQuery = window.matchMedia('(prefers-color-scheme: dark)');
    const handleChange = (e: MediaQueryListEvent) => {
      setSystemTheme(e.matches ? 'dark' : 'light');
    };
    setSystemTheme(mediaQuery.matches ? 'dark' : 'light');
    mediaQuery.addEventListener('change', handleChange);
    return () => mediaQuery.removeEventListener('change', handleChange);
  }, []);

  return systemTheme;
}
```

## 六点五、系统主题实现详解

### 6.5.1 核心概念

**System Theme (跟随系统)** 是一种特殊的主题模式，当用户选择该模式时，应用会实时检测操作系统的主题偏好（浅色/深色）并自动应用对应主题。

### 6.5.2 数据流

```
┌─────────────────────────────────────────────────────────────────┐
│                        用户选择主题                              │
└──────────────────────────┬──────────────────────────────────────┘
                           │
                           ▼
┌──────────────────────────────────────────────────────────────────┐
│                    localStorage 存储                            │
│                  ('plan-todos-theme': 'system')                  │
└──────────────────────────┬───────────────────────────────────────┘
                           │
                           ▼
┌──────────────────────────────────────────────────────────────────┐
│                   getEffectiveTheme()                           │
│  ┌────────────────────────────────────────────────────────────┐   │
│  │  if (theme === 'system') {                              │   │
│  │    return window.matchMedia('(prefers-color-scheme:    │   │
│  │      dark)').matches ? 'dark' : 'light';               │   │
│  │  }                                                       │   │
│  └────────────────────────────────────────────────────────────┘   │
└──────────────────────────┬───────────────────────────────────────┘
                           │
                           ▼
┌──────────────────────────────────────────────────────────────────┐
│              document.documentElement.setAttribute               │
│              ('data-theme', 'dark' / 'light')                   │
└──────────────────────────┬───────────────────────────────────────┘
                           │
                           ▼
┌──────────────────────────────────────────────────────────────────┐
│                   CSS 变量生效                                   │
│         [data-theme="dark"] { --color-bg: #0F172A; }          │
└──────────────────────────────────────────────────────────────────┘
```

### 6.5.4 动态监听

当用户选择"跟随系统"时，应用会监听系统主题变化：

```tsx
// 监听系统主题变化
useEffect(() => {
  if (theme !== 'system') return;

  const mediaQuery = window.matchMedia('(prefers-color-scheme: dark)');
  const handleChange = () => {
    applyTheme('system'); // 重新应用主题
  };

  mediaQuery.addEventListener('change', handleChange);
  return () => mediaQuery.removeEventListener('change', handleChange);
}, [theme, applyTheme]);
```

## 十一、风险与限制

1. **搜索性能**：当前使用 SQL LIKE 查询，大数据量时可能需优化
2. **动画性能**：过多 Framer Motion 可能影响性能，需控制使用
3. **浏览器兼容性**：matchMedia API 需 IE10+，现代浏览器均支持
