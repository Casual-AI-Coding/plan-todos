## 问题分析

### 1. React 反模式：setState in useEffect

**当前问题**：

```tsx
// ❌ 反模式 - 在 useEffect 中直接调用 setState
useEffect(() => {
  if (isLoaded.current) return;
  isLoaded.current = true;
  loadData(); // 内部会调用 setDashboard(data)
}, []);
```

**影响文件**（12处）：
- Dashboard.tsx
- TodosView.tsx
- PlansView.tsx
- TargetsView.tsx
- MilestonesView.tsx
- StatisticsView.tsx
- ViewsView.tsx
- SettingsTagsView.tsx
- useSystemTheme.ts

**为什么有问题**：
- React 官方不推荐在 effect 中同步调用 setState
- 会导致级联渲染，影响性能
- 违反 "You Might Not Need an Effect" 原则

### 2. 未使用变量

**当前问题**：~24 个 unused variable 警告

**典型模式**：
```tsx
// ❌ 定义了但未使用
const { title, content } = data;
// 使用了 content，但 title 没用到

// ✅ 正确做法
const { title: _title, content } = data;
// 或
const { content } = data;
```

### 3. 加载状态不统一

**当前问题**：
- 加载时显示简单的 "加载中..." 文本
- Skeleton 组件已创建但未使用
- 各 view 加载状态不一致

### 4. 无障碍支持不足

**当前问题**：
- 缺少 Focus 可见状态
- 键盘导航体验不佳
- 深色模式下部分组件对比度不足

### 5. API 层缺乏健壮性

**当前问题**：
- 无请求缓存
- 无错误重试
- 无请求取消
- 网络错误处理不一致

## 推荐方案：保守优化

### 1. useDataLoader Hook 设计

```typescript
// src/hooks/useDataLoader.ts

interface UseDataLoaderOptions<T> {
  fetchFn: () => Promise<T>;
  onSuccess?: (data: T) => void;
  onError?: (error: Error) => void;
  enabled?: boolean; // 手动控制是否加载
}

interface UseDataLoaderReturn<T> {
  data: T | null;
  isLoading: boolean;
  error: Error | null;
  reload: () => void;
}

export function useDataLoader<T>({
  fetchFn,
  onSuccess,
  onError,
  enabled = true,
}: UseDataLoaderOptions<T>): UseDataLoaderReturn<T> {
  const [data, setData] = useState<T | null>(null);
  const [isLoading, setIsLoading] = useState(true);
  const [error, setError] = useState<Error | null>(null);
  const isMounted = useRef(true);

  const load = useCallback(async () => {
    if (!enabled) return;
    
    setIsLoading(true);
    setError(null);
    
    try {
      const result = await fetchFn();
      if (isMounted.current) {
        setData(result);
        onSuccess?.(result);
      }
    } catch (err) {
      if (isMounted.current) {
        setError(err as Error);
        onError?.(err as Error);
      }
    } finally {
      if (isMounted.current) {
        setIsLoading(false);
      }
    }
  }, [fetchFn, enabled, onSuccess, onError]);

  useEffect(() => {
    isMounted.current = true;
    load();
    
    return () => {
      isMounted.current = false;
    };
  }, [load]);

  return { data, isLoading, error, reload: load };
}
```

**使用方式**：

```tsx
// ❌ 之前
const [data, setData] = useState(null);
const isLoaded = useRef(false);

useEffect(() => {
  if (isLoaded.current) return;
  isLoaded.current = true;
  loadData();
}, []);

function loadData() {
  getData().then(d => setData(d));
}

// ✅ 之后
const { data, isLoading, error, reload } = useDataLoader({
  fetchFn: getData,
  onError: (e) => console.error(e),
});
```

### 4. API 缓存设计

```typescript
// 简单内存缓存
const cache = new Map<string, { data: unknown; timestamp: number }>();
const CACHE_TTL = 5 * 60 * 1000; // 5 minutes

export async function cachedFetch<T>(
  key: string,
  fetcher: () => Promise<T>
): Promise<T> {
  const cached = cache.get(key);
  
  if (cached && Date.now() - cached.timestamp < CACHE_TTL) {
    return cached.data as T;
  }
  
  const data = await fetcher();
  cache.set(key, { data, timestamp: Date.now() });
  
  return data;
}

// 使用
const dashboard = await cachedFetch('dashboard', getDashboard);
```
