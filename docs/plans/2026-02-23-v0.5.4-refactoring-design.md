### TanStack Query (React Query)

**官网**: https://tanstack.com/query/latest

TanStack Query 是 React 社区最流行的服务端状态管理库，被 React 官方推荐使用。

#### 核心概念

```
┌─────────────────────────────────────────────────────────────┐
│                     TanStack Query                         │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐ │
│  │ Query  │    │Mutation│    │  Cache │    │Optimistic│ │
│  │  获取   │    │  突变   │    │  缓存   │    │  更新   │ │
│  └────┬────┘    └────┬────┘    └────┬────┘    └────┬────┘ │
│       │             │             │             │        │
│       └─────────────┴─────────────┴─────────────┘        │
│                                                             │
│  自动重试 │ 后台更新 │ 竞态处理 │ 预加载 │ 分页    │
└─────────────────────────────────────────────────────────────┘
```

| 功能          | 说明                       |
| ------------- | -------------------------- |
| 自动缓存      | 相同 queryKey 自动复用缓存 |
| 后台更新      | 窗口重新获得焦点时自动刷新 |
| 乐观更新      | 操作立即反映，失败时回滚   |
| 预加载        | prefetchQuery 提前加载数据 |
| 分页/无限滚动 | 内置支持                   |

#### 为什么选择 TanStack Query

1. **React 官方推荐** - React 文档将 TanStack Query 列为推荐方案
2. **TypeScript 优先** - 完美的类型支持
3. **零配置** - 默认值已经很合理
4. **活跃社区** - 20k+ stars，持续维护

### Zustand

**官网**: https://zustand-demo.pmnd.rs/

Zustand 是一个轻量级的状态管理库，名字来源于德语"状态"(Zustand)。

#### 核心概念

```
┌─────────────────────────────────────────────────────────────┐
│                        Zustand                            │
├─────────────────────────────────────────────────────────────┤
│  create((set, get) => ({                                  │
│    // State                                              │
│    count: 0,                                             │
│    // Actions                                            │
│    increment: () => set(state => ({ count: state.count+1 })),│
│    decrement: () => set(state => ({ count: state.count-1 })),│
│  }))                                                      │
│                                                             │
│  ═══════════════════════════════════════════════════════    │
│                                                             │
│  特点:                                                     │
│  • 极简 API - 只有 create() 一个函数                      │
│  • 无 Provider 嵌套 - 无需包裹组件树                      │
│  • 灵活更新 - 支持 immer 或直接修改                       │
│  • 跨组件共享 - 像 useState 一样简单                      │
└─────────────────────────────────────────────────────────────┘
```

| 特性        | 说明                   |
| ----------- | ---------------------- |
| 极简 API    | 只需一个 create() 函数 |
| 无 Provider | 不需要包裹组件树       |
| TypeScript  | 完美的类型推断         |
| 中间件      | 支持 persist、immer 等 |

#### 为什么选择 Zustand

1. **比 Redux 简单 100 倍** - 没有 action/reducer/dispatch
2. **比 Context 更轻量** - 按需订阅，不触发重渲染
3. **社区认可** - 20k+ stars，Vercel 团队也在用
4. **学习成本极低** - 5 分钟上手

### 乐观更新 (Optimistic Updates)

乐观更新是一种用户体验优化技术：先更新 UI，再异步请求服务器。

#### 工作原理

```
用户点击 → 立即更新 UI → 请求服务器 → 成功: 保持 / 失败: 回滚
```

| 阶段     | 传统方式 | 乐观更新 |
| -------- | -------- | -------- |
| 用户点击 | 转圈等待 | 立即响应 |
| 网络请求 | 同步进行 | 后台进行 |
| 请求失败 | 显示错误 | 自动回滚 |
| 体验     | ❌ 慢    | ✅ 快    |

#### React Query 乐观更新示例

```typescript
useMutation({
  mutationFn: updateTodo,
  // 1. 请求前
  onMutate: async (newTodo) => {
    await queryClient.cancelQueries(["todos"]);
    const previousTodos = queryClient.getQueryData(["todos"]);

    // 2. 立即更新缓存
    queryClient.setQueryData(["todos"], (old) =>
      old.map((t) => (t.id === newTodo.id ? newTodo : t)),
    );

    return { previousTodos };
  },
  // 3. 请求失败时回滚
  onError: (err, newTodo, context) => {
    queryClient.setQueryData(["todos"], context.previousTodos);
  },
  // 4. 请求完成后
  onSettled: () => {
    queryClient.invalidateQueries(["todos"]);
  },
});
```

## 问题分析

### 1. React 反模式：setState in useEffect

**当前问题**：12 处使用 `isLoaded.current` 防止重复加载

```tsx
// ❌ 反模式
useEffect(() => {
  if (isLoaded.current) return;
  isLoaded.current = true;
  loadData();
}, []);
```

**为什么有问题**：

- React 官方推荐使用数据获取库
- 手动管理加载状态容易出错
- 缺乏缓存、去重、预获取等能力

### 2. 状态管理混乱

**当前问题**：

- 状态分散在各个组件中
- 组件间状态共享困难
- 缺乏全局状态管理

### 3. API 层缺乏健壮性

**当前问题**：

- 无请求缓存
- 无错误重试
- 无乐观更新
- 网络错误处理不一致

### Step 2: 创建 QueryClient 配置

**文件**: `src/lib/query.ts`

```typescript
import { QueryClient } from "@tanstack/react-query";

export const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      // 数据在 5 分钟内被认为是新鲜的，不会自动重新获取
      staleTime: 5 * 60 * 1000,
      // 缓存数据 10 分钟后被垃圾回收
      gcTime: 10 * 60 * 1000,
      // 请求失败时重试 2 次
      retry: 2,
      // 切换窗口时重新获取
      refetchOnWindowFocus: false,
    },
    mutations: {
      // 突变失败时不重试
      retry: 0,
    },
  },
});
```

import { create } from "zustand";
import type { ThemeId } from "@/lib/themes/registry";

interface AppState {
  // UI State
  sidebarOpen: boolean;
  toggleSidebar: () => void;
  closeSidebar: () => void;

  // Theme State
  theme: ThemeId;
  setTheme: (theme: ThemeId) => void;

  // Filters (全局筛选状态)
  selectedTags: string[];
  setSelectedTags: (tags: string[]) => void;
  clearFilters: () => void;

  // Mobile menu
  mobileMenuOpen: boolean;
  setMobileMenuOpen: (open: boolean) => void;
}

export const useAppStore = create<AppState>((set) => ({
  // UI
  sidebarOpen: false,
  toggleSidebar: () => set((state) => ({ sidebarOpen: !state.sidebarOpen })),
  closeSidebar: () => set({ sidebarOpen: false }),

  // Theme
  theme: "light",
  setTheme: (theme) => set({ theme }),

  // Filters
  selectedTags: [],
  setSelectedTags: (tags) => set({ selectedTags: tags }),
  clearFilters: () => set({ selectedTags: [] }),

  // Mobile
  mobileMenuOpen: false,
  setMobileMenuOpen: (open) => set({ mobileMenuOpen: open }),
}));

### Step 4: 创建数据获取 Hooks

**文件**: `src/hooks/useQueries.ts`

```typescript
import { useQuery, useMutation, useQueryClient } from "@tanstack/react-query";
import {
  getDashboard,
  getTodos,
  createTodo,
  updateTodo,
  deleteTodo,
} from "@/lib/api";

// ============ Dashboard ============
export function useDashboard() {
  return useQuery({
    queryKey: ["dashboard"],
    queryFn: getDashboard,
  });
}

// ============ Todos ============
export function useTodos(filters?: { status?: string; tags?: string[] }) {
  return useQuery({
    queryKey: ["todos", filters],
    queryFn: () => getTodos(filters),
  });
}

export function useCreateTodo() {
  const queryClient = useQueryClient();

  return useMutation({
    mutationFn: createTodo,
    onSuccess: () => {
      // 刷新 todos 列表
      queryClient.invalidateQueries({ queryKey: ["todos"] });
      // 刷新 dashboard
      queryClient.invalidateQueries({ queryKey: ["dashboard"] });
    },
  });
}

export function useUpdateTodo() {
  const queryClient = useQueryClient();

  return useMutation({
    mutationFn: ({ id, data }: { id: string; data: Partial<Todo> }) =>
      updateTodo(id, data),
    // 乐观更新
    onMutate: async ({ id, data }) => {
      await queryClient.cancelQueries({ queryKey: ["todos"] });
      const previousTodos = queryClient.getQueryData(["todos"]);

      queryClient.setQueryData(["todos"], (old: Todo[]) =>
        old?.map((t) => (t.id === id ? { ...t, ...data } : t)),
      );

      return { previousTodos };
    },
    onError: (err, variables, context) => {
      queryClient.setQueryData(["todos"], context?.previousTodos);
    },
    onSettled: () => {
      queryClient.invalidateQueries({ queryKey: ["todos"] });
    },
  });
}

export function useDeleteTodo() {
  const queryClient = useQueryClient();

  return useMutation({
    mutationFn: deleteTodo,
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ["todos"] });
    },
  });
}
```

### Step 5: 迁移现有 View

**迁移前** - `src/app/views/Dashboard.tsx`

```typescript
export function Dashboard() {
  const [dashboard, setDashboard] = useState<Dashboard | null>(null);
  const isLoaded = useRef(false);

  async function loadData() {
    try {
      const data = await getDashboard();
      if (isLoaded.current) setDashboard(data);
    } catch (error) {
      console.error("Failed to load dashboard:", error);
    }
  }

  useEffect(() => {
    if (isLoaded.current) return;
    isLoaded.current = true;
    loadData();
  }, []);

  if (!dashboard) return <div>加载中...</div>;

  // ... render
}
```

    );
  }

  return (

      <div className="dashboard">

    </FadeIn>
  );
}
