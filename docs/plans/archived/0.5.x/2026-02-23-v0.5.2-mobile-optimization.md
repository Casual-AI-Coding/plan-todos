# v0.5.2 - 移动端优化设计文档

> 日期: 2026-02-23
> 版本: 0.5.2
> 状态: 设计阶段

---

## 1. 概述

进一步优化移动端用户体验，修复刘海遮挡问题并调整视图密度。

---

## 2. 问题分析

### 2.1 当前问题

| 问题 | 严重程度 | 原因 |
|------|----------|------|
| 汉堡菜单被刘海遮挡 | 🔴 严重 | 缺少 `padding-top: env(safe-area-inset-top)` |
| Sidebar 被刘海遮挡 | 🔴 严重 | 缺少 `padding-top` |
| Sidebar 右侧白色块 | 🟡 中等 | 缺少关闭按钮/头部，背景延伸问题 |
| 移动端视图太拥挤/空隙太大 | 🟡 中等 | 间距/字体/组件未针对移动端优化 |

### 2.2 需要优化的地方

1. **Header**: 添加顶部安全区域 padding
2. **Sidebar**: 添加顶部安全区域 padding
3. **移动端间距**: 减小 p-4/p-3 为 p-2
4. **移动端字体**: 减小 text-lg/text-md 为 text-base/text-sm
5. **移动端组件**: 减小按钮、卡片内边距

---

## 3. 解决方案

### 3.1 修复刘海遮挡

#### 3.1.1 移动端 Header

```
文件: src/app/page.tsx

修改:
className="flex items-center h-12 px-4 border-b pt-[env(safe-area-inset-top)]"
```

#### 3.1.2 移动端 Sidebar Overlay

```
文件: src/app/page.tsx

修改:
style={{
  ...
  paddingTop: 'env(safe-area-inset-top)',
}}
```

#### 3.1.3 移动端 Main Content

```
文件: src/app/page.tsx

修改:
style={{
  backgroundColor: 'var(--color-bg)',
  paddingBottom: 'calc(4rem + env(safe-area-inset-bottom))',
}}
```

### 3.2 移动端视图优化

#### 3.2.1 通用移动端样式

创建移动端专用类或在现有类上添加响应式变体：

| 元素 | 桌面端 | 移动端 |
|------|--------|--------|
| 容器 padding | p-4 | p-2 |
| 标题 | text-lg | text-base |
| 副标题 | text-md | text-sm |
| 卡片内边距 | p-3 | p-2 |
| 按钮内边距 | px-4 py-2 | px-3 py-1.5 |
| 间距 | gap-4 | gap-2 |

#### 3.2.2 典型组件示例

**Card 组件 (移动端)**:
```tsx
// 当前
className="p-4 rounded-lg"

// 移动端优化
className="p-2 sm:p-4 rounded-md sm:rounded-lg"
```

**标题 (移动端)**:
```tsx
// 当前
className="text-lg font-semibold"

// 移动端优化
className="text-base sm:text-lg font-medium sm:font-semibold"
```
