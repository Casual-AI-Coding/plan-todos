### 3.3 移动端汉堡菜单

**触发方式**: 点击左上角 ☰ 按钮

**交互流程**:
1. 用户点击 ☰ 按钮
2. Sidebar 从左侧滑入 (transform: translateX)
3. 背景显示半透明遮罩 (rgba(0,0,0,0.5))
4. 点击遮罩或返回按钮关闭

**Sidebar 移动端样式**:
- 宽度: 13rem (全展开) 或 4rem (仅图标)
- 高度: 100vh
- 位置: fixed, left: 0, top: 0
- z-index: 50 (高于内容)

### 3.5 视口和 CSS 修复

#### layout.tsx viewport 配置
```tsx
export const viewport = {
  width: 'device-width',
  height: 'device-height',
  initialScale: 1,
  maximumScale: 1,
  userScalable: false,
  viewportFit: 'cover',
};
```

#### globals.css 移动端修复
```css
html {
  -webkit-text-size-adjust: 100%;
  -webkit-overflow-scrolling: touch;
}

body {
  height: 100%;
  overflow: hidden;
  position: fixed;
  width: 100%;
}

@supports (height: 100dvh) {
  body {
    height: 100dvh;
  }
}
```
