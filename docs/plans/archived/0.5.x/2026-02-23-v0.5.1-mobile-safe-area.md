# v0.5.1 - 移动端安全区域适配设计文档

> 日期: 2026-02-23
> 版本: 0.5.1
> 状态: 设计阶段

---

## 1. 概述

修复移动端刘海屏/全面屏的安全区域适配问题，确保内容不被系统 UI 遮挡。

---

## 2. 问题分析

### 2.1 当前问题

| 问题                       | 严重程度 | 原因                     |
| -------------------------- | -------- | ------------------------ |
| 顶部刘海遮挡汉堡菜单       | 🔴 严重  | 缺少顶部安全区域 padding |
| 底部系统导航遮挡 BottomNav | 🔴 严重  | 缺少底部安全区域 padding |
| 侧边栏被刘海遮挡           | 🟡 中等  | 缺少顶部安全区域         |

### 2.2 用户反馈 (截图)

- 截图1: 顶部猫头图标与"Plan"文字重叠，汉堡菜单被遮挡
- 截图2: 底部虚拟导航键区域与 BottomNav 重叠，按钮难以点击

---

## 3. 解决方案

### 3.1 技术原理

使用 CSS `env()` 函数读取系统安全区域：

| CSS 属性                      | 说明         | 用户手势导航 | 虚拟导航键 |
| ----------------------------- | ------------ | ------------ | ---------- |
| `env(safe-area-inset-top)`    | 顶部安全区域 | 0px          | 0px        |
| `env(safe-area-inset-bottom)` | 底部安全区域 | 0px          | ~20-40px   |

**优点**: 无需 JS 检测，系统自动适配

### 3.2 修改方案

#### 3.2.1 移动端 Header

```
文件: src/app/page.tsx

修改前:
<header className="flex items-center h-12 px-4 border-b">

修改后:
<header className="flex items-center h-12 px-4 border-b pt-[env(safe-area-inset-top)]">
```

#### 3.2.2 移动端 Sidebar

```
文件: src/app/page.tsx

Sidebar overlay 添加:
style={{ paddingTop: 'env(safe-area-inset-top)' }}
```

#### 3.2.3 移动端 BottomNav

```
文件: src/components/layout/BottomNav.tsx

修改前:
<nav className="fixed bottom-0 left-0 right-0 md:hidden z-50 border-t">

修改后:
<nav className="fixed bottom-0 left-0 right-0 md:hidden z-50 border-t pb-[env(safe-area-inset-bottom)]">
```

#### 3.2.4 main 内容区域 padding

```
文件: src/app/page.tsx

修改前:
className="flex-1 overflow-auto pb-16"

修改后:
className="flex-1 overflow-auto pb-16 pb-[env(safe-area-inset-bottom)]"
```
