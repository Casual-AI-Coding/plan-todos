**Step 1: Add withTauriError helper function**

Add at the top of api.ts after the isTauri check:
```typescript
// Helper to wrap Tauri invoke calls with error handling
export async function withTauriError<T>(fn: () => Promise<T>): Promise<T> {
  if (!isTauri()) {
    throw new Error('This app must run in Tauri');
  }
  try {
    return await fn();
  } catch (e) {
    console.error('[Tauri Error]', e);
    throw e;
  }
}
```

## Task 5: Fix ESLint Errors (6 errors)

**Files:**
- Modify: `src/app/page.tsx`
- Modify: `src/components/layout/Sidebar.tsx`

**Current Errors:**
1. `setState in effect` - 5 files (page.tsx, Sidebar.tsx, ThemeSelector.tsx, useGlassSettings.ts, useTheme.ts)
2. `Math.random() in render` - ProgressRing.tsx

**Step 1: Fix setState in effect errors**

For localStorage initialization, use this pattern instead:
```tsx
// Instead of:
useEffect(() => {
  const saved = localStorage.getItem('key');
  if (saved) setState(saved);
}, []);

// Use:
const [state, setState] = useState(() => {
  // Initialize state from localStorage during useState
  if (typeof window !== 'undefined') {
    return localStorage.getItem('key') || defaultValue;
  }
  return defaultValue;
});
```

**Step 2: Fix ProgressRing Math.random()**

Use useId() from React or a static counter:
```tsx
// Instead of:
const gradientId = `progress-gradient-${Math.random()...}`;

// Use:
const gradientId = useId(); // React 18+
```
