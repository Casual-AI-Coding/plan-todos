#### 交互状态

**窗口控制按钮**

- 默认：透明背景
- 悬停（非关闭按钮）：theme.bgHover
- 悬停（关闭按钮）：#E81123（Windows 风格红）
- 悬停关闭按钮文字：#FFFFFF
- 点击：无变化
- 禁用：50% 透明度

#### 窗口拖拽

- 标题栏区域支持拖拽移动窗口
- 双击标题栏区域：最大化/还原切换

## 技术细节

### Tauri 配置

```json
{
  "app": {
    "windows": [
      {
        "decorations": false,
        "titleBarStyle": "hidden"
      }
    ]
  }
}
```

### Rust 命令

```rust
#[tauri::command]
fn minimize_window(window: Window)

#[tauri::command]
fn toggle_maximize(window: Window)

#[tauri::command]
fn close_window(window: Window)

#[tauri::command]
fn is_maximized(window: Window) -> bool
```

### 前端 API

```typescript
// src/lib/api.ts
export async function minimizeWindow(): Promise<void>;
export async function toggleMaximize(): Promise<void>;
export async function closeWindow(): Promise<void>;
export async function isMaximized(): Promise<boolean>;
```

### 组件结构

```
src/components/ui/
└── TitleBar.tsx        # 标题栏主组件
    ├── WindowControlButton  # 窗口控制按钮（内部组件）
```

## 已知限制

1. **拖拽区域**：仅标题栏区域可拖拽，不包含窗口控制按钮
2. **平台差异**：macOS 风格的窗口控制按钮位置可能需要调整
3. **透明窗口**：由于启用了透明窗口，标题栏需要设置背景色避免内容穿透
